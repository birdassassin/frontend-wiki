### 需求

将一列数组的数字按照从大到小或者从小到大的顺序排序。

### 原理

假设是从小到大排序，循环数组，比较第一个a和下一个b元素的大小，如果a大于b，则调换顺序。

### 函数实现

```javascript
function bubblingSort(arg, type=&amp;amp;quot;asc&amp;amp;quot;) {
  let t 
  if(type === &amp;amp;#039;des&amp;amp;#039;) {
    for(let i = 0, len = arg.length; i &amp;amp;lt; len; i++) {
      for(let j = 0; j &amp;amp;lt; len-i; j++) {
        if(arg[j] &amp;amp;lt; arg[j+1]) {
          t = arg[j]
          arg[j] = arg[j+1]
          arg[j+1] = t
        }
      }
    }
  } else {
    for(let i = 0, len = arg.length; i &amp;amp;lt; len; i++) {
      for(let j = 0; j &amp;amp;lt; len-i; j++) {
        if(arg[j] &amp;amp;gt; arg[j+1]) {
          t = arg[j]
          arg[j] = arg[j+1]
          arg[j+1] = t
        }
      }
    }
  }
  return arg
}

// 降序
const s = bubblingSort([1,5,4,8,2,0,3,3], &amp;amp;#039;des&amp;amp;#039;)
console.log(s) // [8,5,4,3,3,2,1,0]

//升序
const s = bubblingSort([1,5,4,8,2,0,3,3], &amp;amp;#039;asc&amp;amp;#039;)
console.log(s) // [0,1,2,3,3,4,5,8]
```

### 缺点

冒泡排序的名字是如此的可爱，但是它的时间复杂度达到了惊人的O(N²)。
