# 解构赋值

> 🟢 **初级** — 适合前端初学者，掌握数组和对象的解构。

---

## 1. 数组解构

### 1.1 基本用法

```javascript
// ES5
const arr = [1, 2, 3];
const a = arr[0];
const b = arr[1];
const c = arr[2];

// ES6 数组解构
const [a, b, c] = [1, 2, 3];
console.log(a); // 1
console.log(b); // 2
console.log(c); // 3
```

### 1.2 跳过元素

```javascript
const [first, , third] = [1, 2, 3];
console.log(first); // 1
console.log(third); // 3
```

### 1.3 默认值

```javascript
const [a, b = 10] = [1];
console.log(a); // 1
console.log(b); // 10
```

### 1.4 剩余参数

```javascript
const [first, ...rest] = [1, 2, 3, 4, 5];
console.log(first); // 1
console.log(rest); // [2, 3, 4, 5]
```

## 2. 对象解构

### 2.1 基本用法

```javascript
// ES5
const user = { name: 'Alice', age: 25 };
const name = user.name;
const age = user.age;

// ES6 对象解构
const { name, age } = { name: 'Alice', age: 25 };
console.log(name); // 'Alice'
console.log(age); // 25
```

### 2.2 重命名变量

```javascript
const { name: userName, age: userAge } = { name: 'Alice', age: 25 };
console.log(userName); // 'Alice'
console.log(userAge); // 25
```

### 2.3 默认值

```javascript
const { name, age = 18 } = { name: 'Alice' };
console.log(name); // 'Alice'
console.log(age); // 18
```

### 2.4 嵌套对象解构

```javascript
const user = {
  name: 'Alice',
  address: {
    city: 'Beijing',
    street: 'Main Street'
  }
};

const { name, address: { city, street } } = user;
console.log(city); // 'Beijing'
console.log(street); // 'Main Street'
```

## 3. 函数参数解构

### 3.1 对象参数解构

```javascript
// ES5
function greet(options) {
  const name = options.name || 'Guest';
  const greeting = options.greeting || 'Hello';
  console.log(greeting + ', ' + name);
}

// ES6
function greet({ name = 'Guest', greeting = 'Hello' } = {}) {
  console.log(greeting + ', ' + name);
}

greet({ name: 'Alice' }); // Hello, Alice
greet(); // Hello, Guest
```

### 3.2 数组参数解构

```javascript
function sum([a, b]) {
  return a + b;
}

sum([1, 2]); // 3
```

## 4. 实际应用场景

### 4.1 交换变量

```javascript
let a = 1;
let b = 2;

// ES5
const temp = a;
a = b;
b = temp;

// ES6
[a, b] = [b, a];
```

### 4.2 从函数返回多个值

```javascript
function getUser() {
  return ['Alice', 25, 'Beijing'];
}

const [name, age, city] = getUser();
```

### 4.3 处理 API 响应

```javascript
const response = {
  data: {
    users: [{ id: 1, name: 'Alice' }, { id: 2, name: 'Bob' }],
    total: 2
  },
  status: 200
};

const { data: { users, total }, status } = response;
```
