# 箭头函数

> 🟢 **初级** — 适合前端初学者，掌握箭头函数的基本用法。

---

## 1. 基本语法

### 1.1 基本形式

```javascript
// ES5 普通函数
function add(a, b) {
  return a + b;
}

// ES6 箭头函数
const add = (a, b) => a + b;
```

### 1.2 无参数

```javascript
// 无参数需要括号
const hello = () => 'Hello World';
```

### 1.3 单个参数

```javascript
// 单个参数可以省略括号
const double = x => x * 2;

// 也可以保留括号
const double = (x) => x * 2;
```

### 1.4 多个参数

```javascript
// 多个参数必须有括号
const sum = (a, b, c) => a + b + c;
```

### 1.5 多行函数体

```javascript
// 多行需要花括号和 return
const calculate = (a, b) => {
  const sum = a + b;
  const product = a * b;
  return sum + product;
};
```

## 2. 箭头函数与 this

### 2.1 this 指向问题

```javascript
// ES5 中的 this 问题
const person = {
  name: 'Alice',
  greet: function() {
    setTimeout(function() {
      console.log('Hello, ' + this.name); // ❌ this 指向 window
    }, 1000);
  }
};

// 解决方案 1: 保存 this
const person = {
  name: 'Alice',
  greet: function() {
    const self = this;
    setTimeout(function() {
      console.log('Hello, ' + self.name); // ✅ 使用 self
    }, 1000);
  }
};

// ES6 箭头函数自动绑定外层 this
const person = {
  name: 'Alice',
  greet: function() {
    setTimeout(() => {
      console.log('Hello, ' + this.name); // ✅ this 指向 person
    }, 1000);
  }
};
```

### 2.2 箭头函数不适合作为方法

```javascript
const obj = {
  name: 'Alice',
  greet: () => {
    console.log(this.name); // ❌ this 指向外层作用域
  }
};

obj.greet(); // undefined
```

---

## 3. 箭头函数不适用场景

| 场景 | 是否适用 | 原因 |
|------|----------|------|
| 对象方法 | ❌ | this 不指向对象 |
| 构造函数 | ❌ | 不能作为构造函数 |
| 原型方法 | ❌ | this 指向问题 |
| 需要 arguments | ❌ | 没有 arguments 对象 |
| 需要 this 动态绑定 | ❌ | this 词法绑定 |

## 4. 练习题

1. **转换为箭头函数**：
```javascript
function multiply(a, b) {
  return a * b;
}
```

2. **修复 this 问题**：
```javascript
const button = document.querySelector('button');
button.addEventListener('click', function() {
  setTimeout(function() {
    this.style.color = 'red';
  }, 1000);
});
```

3. **判断输出**：
```javascript
const obj = {
  count: 0,
  increment: () => {
    this.count++;
  }
};
obj.increment();
console.log(obj.count);
```
