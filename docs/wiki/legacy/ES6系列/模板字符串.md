# 模板字符串

> 🟢 **初级** — 适合前端初学者，掌握模板字符串的基本用法。

---

## 1. 基本语法

### 1.1 字符串拼接

```javascript
// ES5
const name = 'Alice';
const greeting = 'Hello, ' + name + '!';

// ES6 模板字符串
const greeting = `Hello, ${name}!`;
```

### 1.2 多行字符串

```javascript
// ES5
const html = '<div>' +
             '  <p>Hello</p>' +
             '</div>';

// ES6 模板字符串
const html = `
<div>
  <p>Hello</p>
</div>
`;
```

### 1.3 表达式求值

```javascript
const a = 10;
const b = 20;
const result = `${a} + ${b} = ${a + b}`;
console.log(result); // "10 + 20 = 30"
```

## 2. 标签模板

### 2.1 基本用法

```javascript
function highlight(strings, ...values) {
  let result = '';
  strings.forEach((str, i) => {
    result += str;
    if (values[i]) {
      result += `<strong>${values[i]}</strong>`;
    }
  });
  return result;
}

const name = 'Alice';
const age = 25;
const html = highlight`Name: ${name}, Age: ${age}`;
// Result: "Name: <strong>Alice</strong>, Age: <strong>25</strong>"
```

### 2.2 实际应用：XSS 防护

```javascript
function sanitize(strings, ...values) {
  let result = '';
  strings.forEach((str, i) => {
    result += str;
    if (values[i]) {
      // 转义特殊字符
      const escaped = String(values[i])
        .replace(/&/g, '&amp;')
        .replace(/</g, '&lt;')
        .replace(/>/g, '&gt;');
      result += escaped;
    }
  });
  return result;
}

const userInput = '<script>alert("XSS")</script>';
const safeHtml = sanitize`User input: ${userInput}`;
// Result: "User input: &lt;script&gt;alert(&quot;XSS&quot;)&lt;/script&gt;"
```
