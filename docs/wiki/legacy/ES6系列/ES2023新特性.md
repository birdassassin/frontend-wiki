## 1. Array.prototype.findLast

### 1.1 基本用法

```javascript
const arr = [1, 2, 3, 4, 5];

// 从后往前查找第一个满足条件的元素
const lastEven = arr.findLast(num => num % 2 === 0);
console.log(lastEven); // 4

// ES5 方式（需要反转数组）
const lastEvenES5 = [...arr].reverse().find(num => num % 2 === 0);
console.log(lastEvenES5); // 4
```

### 1.2 与 find 的对比

```javascript
const arr = [1, 2, 3, 4, 5];

// find 从前往后
const firstEven = arr.find(num => num % 2 === 0);
console.log(firstEven); // 2

// findLast 从后往前
const lastEven = arr.findLast(num => num % 2 === 0);
console.log(lastEven); // 4
```

## 2. Array.prototype.findLastIndex

### 2.1 基本用法

```javascript
const arr = [1, 2, 3, 4, 5];

// 从后往前查找第一个满足条件的索引
const lastEvenIndex = arr.findLastIndex(num => num % 2 === 0);
console.log(lastEvenIndex); // 3

// ES5 方式
const lastEvenIndexES5 = arr.length - 1 - [...arr].reverse().findIndex(num => num % 2 === 0);
console.log(lastEvenIndexES5); // 3
```

## 3. Array.prototype.toSorted

### 3.1 基本用法

```javascript
const arr = [3, 1, 4, 1, 5, 9];

// 原数组不变，返回新数组
const sorted = arr.toSorted();
console.log(arr);     // [3, 1, 4, 1, 5, 9]
console.log(sorted);  // [1, 1, 3, 4, 5, 9]

// 自定义排序
const sortedDesc = arr.toSorted((a, b) => b - a);
console.log(sortedDesc); // [9, 5, 4, 3, 1, 1]
```

## 4. Array.prototype.toReversed

### 4.1 基本用法

```javascript
const arr = [1, 2, 3, 4, 5];

// 原数组不变，返回新数组
const reversed = arr.toReversed();
console.log(arr);      // [1, 2, 3, 4, 5]
console.log(reversed); // [5, 4, 3, 2, 1]
```

## 5. Array.prototype.toSpliced

### 5.1 基本用法

```javascript
const arr = [1, 2, 3, 4, 5];

// 原数组不变，返回新数组
const spliced = arr.toSpliced(1, 2, 'a', 'b');
console.log(arr);      // [1, 2, 3, 4, 5]
console.log(spliced);  // [1, 'a', 'b', 4, 5]

// 参数说明：startIndex, deleteCount, ...items
```

## 6. Array.prototype.with

### 6.1 基本用法

```javascript
const arr = [1, 2, 3, 4, 5];

// 原数组不变，返回新数组
const updated = arr.with(2, 'x');
console.log(arr);     // [1, 2, 3, 4, 5]
console.log(updated); // [1, 2, 'x', 4, 5]

// 链式调用
const result = arr
  .with(0, 'a')
  .with(1, 'b')
  .with(2, 'c');
console.log(result); // ['a', 'b', 'c', 4, 5]
```

## 7. WeakMap.prototype.getOrSet

### 7.1 基本用法

```javascript
const weakMap = new WeakMap();
const obj = { name: 'Alice' };

// 如果键不存在，设置默认值
const value = weakMap.getOrSet(obj, 'default');
console.log(value); // 'default'

// 如果键存在，返回现有值
const value2 = weakMap.getOrSet(obj, 'new value');
console.log(value2); // 'default'
```
