## 🧠 前端思维模型

### 1. 声明式 vs 命令式

```
命令式: 告诉浏览器"如何做" → 操作DOM、步骤清晰
声明式: 告诉浏览器"要什么" → 描述状态、框架处理细节
```

**实践：** 使用 React/Vue 的声明式语法，但理解底层 DOM 操作原理。

### 2. 单向数据流

```
UI = f(state)

状态 → 渲染 → UI
事件 → 更新状态 → 重新渲染
```

**实践：** 状态是唯一真相源，避免直接修改 DOM。

### 3. 组件化思维

```
页面 → 组件树 → 原子组件
         ↓
    职责单一、可复用、可测试
```

**实践：** 组件拆分遵循单一职责原则，合理设计 props 和事件。

### 4. 渐进式增强

```
核心内容 (HTML) → 样式增强 (CSS) → 交互增强 (JS)
```

**实践：** 确保无 JS 情况下页面仍可访问。

### 5. 性能预算

```
LCP < 2.5s
INP < 200ms  
CLS < 0.1
```

**实践：** 开发时关注性能指标，建立性能预算。

## 📚 推荐学习路径

### 阶段一：基础夯实（1-2个月）

1. **HTML**：MDN HTML 指南、语义化实践
2. **CSS**：Flexbox Froggy、Grid Garden、CSS-Tricks
3. **JavaScript**：MDN JS 指南、《JavaScript 高级程序设计》

### 阶段二：框架入门（1-2个月）

1. **React**：官方文档、React 101、TodoMVC
2. **Vue**：官方文档、Vue Mastery、TodoMVC
3. **TypeScript**：官方文档、TypeScript Handbook

### 阶段三：工程化（1个月）

1. **Vite**：官方文档、从零配置
2. **Webpack**：官方文档、核心概念
3. **测试**：Vitest、React Testing Library

### 阶段四：深入原理（持续）

1. **React 源码**：React 技术揭秘、Fiber 架构
2. **Vue 源码**：Vue Design Patterns、响应式原理
3. **浏览器原理**：《浏览器工作原理与实践》
