## 📚 前端知识体系

前端开发是构建用户界面的技术领域，涵盖从基础语言到高级架构的完整知识链。以下是前端开发者需要掌握的核心知识体系：

### 🎯 基础层

| 技术 | 官网 | 核心内容 |
|------|------|----------|
| **HTML** | [html.spec.whatwg.org](https://html.spec.whatwg.org) | 语义化标签、文档结构、表单、ARIA、SEO |
| **CSS** | [drafts.csswg.org](https://drafts.csswg.org) | Flexbox、Grid、动画、响应式、CSS Modules |
| **JavaScript** | [developer.mozilla.org/en-US/docs/Web/JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) | ES6+、异步编程、事件循环、模块化 |
| **TypeScript** | [typescriptlang.org](https://www.typescriptlang.org) | 类型系统、泛型、接口、高级类型 |
| **HTTP/HTTPS** | [httpwg.org](https://httpwg.org) | 请求方法、状态码、缓存策略、CORS |
| **CDN** | [cloudflare.com](https://www.cloudflare.com) | 内容分发、缓存策略、边缘计算 |

### 🏗️ 框架层

| 框架 | 官网 | 特点 |
|------|------|------|
| **React** | [react.dev](https://react.dev) | 组件化、虚拟DOM、Hooks、并发渲染 |
| **Vue** | [vuejs.org](https://vuejs.org) | 响应式、组合式API、渐进式框架 |
| **Angular** | [angular.io](https://angular.io) | 全功能框架、TypeScript、RxJS |
| **Svelte** | [svelte.dev](https://svelte.dev) | 编译型框架、零运行时开销 |
| **Solid** | [solidjs.com](https://www.solidjs.com) | 细粒度响应式、编译优化 |
